1) 脚本介绍

这是 LeRobot 的数据采集脚本,作用是「通过遥操作(teleop)录制数据集」。注意它是纯数据采集工具,不做策略推理——如果要部署已训练好的策略,应该用 lerobot-rollout(脚本第 16-18 行的注释明确说明了这点)。

整体执行流程:

- record()(lerobot_record.py:325)是被 @parser.wrap() 装饰的入口,由 draccus 把命令行参数解析成 RecordConfig。
- 创建机器人 make_robot_from_config 和遥操作器 make_teleoperator_from_config,建立三条处理管线(teleop动作 / robot动作 / robot观测,默认是 Identity 直通)。
- 创建或 resume 一个 LeRobotDataset,连接硬件,启动键盘监听 init_keyboard_listener。
- 主循环(lerobot_record.py:429)对每个 episode 调一次 record_loop 录制,再调一次 record_loop(reset_time_s,不写盘)给你时间复位环境,然后 save_episode()。
- record_loop(lerobot_record.py:196)是核心:每个控制周期里 get_observation → 处理 → teleop.get_action → 处理 → robot.send_action → add_frame → rerun 显示 → precise_sleep 保持 fps(数据流图见 :169-192)。

3) 控制部分说明 + xvfb-run「下一条没生效」分析

控制机制(control_utils.py:124 的 init_keyboard_listener):

通过 pynput 监听三个按键,设置 events 标志位:

- → 右方向键:exit_early=True → 提前结束当前 episode,进入下一条
- ← 左方向键:rerecord_episode=True + exit_early=True → 丢弃并
- Esc:stop_recording=True → 停止整个录制

record_loop 每个周期检查 events["exit_early"](lerobot_record.py:252)来决定是否 break;主循环检查 stop_recording / rerecord_episode 决定流程走向。
